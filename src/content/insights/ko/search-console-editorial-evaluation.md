## 1. 수치와 본문으로 개선 후보 선정하기

검색 실적에서 페이지, 검색 유형, 기간을 고정하고 노출수, 클릭수, CTR, 평균 게재순위를 확인합니다. 필요에 따라 검색어, 국가, 기기도 살펴봅니다. 노출은 있지만 본문에서 답을 찾기 어려운 페이지는 조사 후보가 될 수 있지만, 낮은 CTR만으로 제목 변경이 필요한지 결정할 수는 없습니다.

페이지를 열어 검색하는 사람이 무엇을 알고 싶어 하는지, 현재 본문에 어떤 설명이 빠져 있는지 적어 봅니다. 표시되지 않는 검색어나 수집되지 않은 행을 검색이 없었다는 증거로 취급하지 않는 것도 중요합니다. Google의 [검색 트래픽 감소 조사 절차](https://developers.google.com/search/docs/monitor-debug/debugging-search-traffic-drops)는 기간, 페이지, 검색어별로 변화를 조사할 때 참고할 수 있습니다.

## 2. 근거를 대조하고 독자에게 유용한 변경 사항 만들기

공식 자료와 실제 공개 페이지를 확인하고 구체적인 예시, 절차, 적용 조건, 참고 링크를 추가합니다. 실측값, 설명을 위한 가상 예시, 미확인 사항을 구분하고, 확인하지 못한 효과를 성과로 쓰지 않습니다. 제목과 description도 본문이 실제로 답하는 내용에 맞춥니다. [Google의 유용한 콘텐츠 자체 평가](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)도 검토할 때 참고할 수 있습니다.

개정안은 Draft PR로 정리하고 변경 부분과 출처, 공개일과 URL의 유지 여부, 번역 대기 여부를 확인합니다. 검토, 병합, 배포, 검색 반영은 각각 별개의 상태입니다. 본문 검토가 끝났다는 사실만으로 실제 서비스에서 읽을 수 있는 상태가 되었다고 판단하지 않습니다.

## 3. 공개일과 비교 조건 고정하기

예를 들어 공개일을 제외한 전 28일과 후 28일을 비교합니다. 대상 URL과 언어, 검색 유형, 국가, 기기, 날짜 경계, 데이터 확정 상태를 두 기간에서 동일하게 맞춥니다. 공개 당일에 배포된 시각이 섞여 있다면 해당 날짜를 제외해 비교 조건을 명확히 할 수 있습니다. 28일은 실무상 관측 기간이며, 모든 기사에 최적인 기간을 보장하는 것은 아닙니다.

| 기록할 항목                     | 확인하는 이유                                |
| ------------------------------- | -------------------------------------------- |
| 공개 일시와 대상 URL            | 비교 기간과 대상을 고정하기 위해             |
| 클릭수·노출수·CTR·평균 게재순위 | 같은 조건에서 변화를 관찰하기 위해           |
| 언어·검색 유형·국가·기기        | 집계 차이에 따른 혼동을 방지하기 위해        |
| 다른 개정·수요·데이터 부족      | 변화 해석에 필요한 제약 사항을 기록하기 위해 |

## 실제 사례: 전후 비교만으로는 개정 효과를 확정할 수 없다

Aceserver Portal의 [WIKI와 알파군 안내 기사](https://asv.acecore.net/ko/stories/wiki-alpha-guide/)에는 질문 예시와 원문 확인 안내를 추가해 2026년 10월 10일에 개정판을 공개했습니다. 평가 기간은 Search Console의 날짜 경계를 기준으로 공개일을 제외한 9월 12일~10월 9일과 10월 11일~11월 7일입니다.

이전 기간에는 최초 공개일과 직전의 다른 개정도 포함됩니다. 여러 변경을 동시에 진행했고, 검색 수요나 적은 건수에 따른 변동도 있으므로 전후 차이를 이번 개정이나 참고 링크만의 효과로 해석할 수 없습니다. 조사 시점에서 유입 개선은 입증되지 않았습니다. 관측값을 기록할 때는 확보한 범위와 확보하지 못한 범위를 구분합니다.

먼저 기사 하나를 대상으로 독자의 의문, 공개된 본문, 확인한 출처, 개정 가설을 기록하고 검토 가능한 변경 사항을 만들어 보세요. 공개 후 비교는 다음 조사 대상을 선택하는 자료로 활용하고, 수치 변화와 그 원인을 구분해 다룹니다. 확인일: 2026년 11월 17일.
