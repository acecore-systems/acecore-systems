Acecore의 여러 공개 사이트는 질문에 제목과 같은 단어가 없어도 관련 페이지를 찾을 수 있도록 Cloudflare Vectorize를 사용합니다. 2026년 8월에는 질의와 공개 페이지의 임베딩 모델을 Cloudflare Workers AI의 BGE-M3로 사이트별로 이전했습니다.

## 별도의 인덱스 준비

모델이 바뀌면 벡터 차원도 달라집니다. 기존 인덱스를 재사용하지 않고 새 인덱스를 만들었으며, 공개 페이지에서 생성한 검색 데이터를 동기화하고 벡터 ID가 일치하는지 확인했습니다. 실제 질의를 시험한 뒤 전환했고 이전 인덱스는 복구용으로 남겼습니다.

## 실제 질문으로 평가

Acecore Systems에서는 대표 질의 12개를 평가했습니다. 기대한 페이지가 10개 질의에서 1위였고, 12개 모두에서 상위 5위 안에 들었습니다. 관련 없는 질의 4개는 당시의 임계값으로 제외됐습니다. 이는 전환 시점의 소규모 평가이며 앞으로의 모든 질의에 대한 정확도를 보장하지 않습니다.

## 방문자 안내 갱신

실제 처리 위치에 맞춰 검색 화면과 개인정보 안내를 갱신했습니다. 일반 키워드 검색은 의미 검색과 함께 계속 사용할 수 있습니다. 앞으로도 관련성, 응답 시간, 인덱스에 공개 정보만 포함되는지 확인합니다.
