# 目的から選ぶサービスUI

2026-10-15。3案目の情報構造と文言を既存Astroサイトへ適用し、追加の選択に合わせて見た目を1案目へ寄せる。公開済みのサービス・価格を増やす変更ではない。

## ページの役割

- トップは困りごとを3つのカードリンクで提示し、Webの整備、業務効率化、IT顧問へ誘導する。ヒーローは文章を左、Cherry英語教室の実績を右に配置する。従来の実績ブロック、支援方針と詳しい説明を下部に残す。
- サービス一覧は「Webを整える」「仕事を効率化する」「安心して運用する」で分類する。カテゴリを選択すると該当群を表示し、URLのhashとブラウザの戻る・進むに追従する。JavaScriptなしでも全サービスと各詳細へのリンクを読める。
- 7つの詳細URLを維持する。運用支援とセキュリティ支援は別の行・別の詳細ページとする。
- Web制作詳細は対象と便益、相談、Cherryの実績を左右に配置し、セクションナビ、価格摘要を先に提示する。提供範囲、条件、進め方、FAQ、技術資料を下部に残す。

## 共通表示

白、薄い水色、鮮明な青いCTAとsansを共通のtokenにする。濃紺の太い見出し、丸いpill型ボタン、大きい青線アイコン、柔らかい薄青のカードを1案目の基調に合わせる。ヘッダ・フッタと共通見出しを含むため、実績、料金、ガイド、問い合わせ、技術解説にも同じ基調が適用される。本文は16pxを基準とし、見出し・ボタンの折り返しとタッチ領域を確保する。

ロゴは既存favicon、実績は既存のCherry画像を使う。アイコンはMITライセンスの`@tabler/icons`から必要なものだけを静的HTMLへ出力し、独自のSVGを描かない。生成された比較用ボードは公開アセットに含めない。

ヒーローの機器外形は生成した透明ラスターを使用し、PC・スマートフォンの画面へ実際のCherryサイトの画像を通常のimgとして重ねる。人物写真や日本語を生成で描き直さない。位置と切り抜きだけをCSSで指定し、機器の外形をCSSやSVGで描かない。小さい画面では文章と実績を縦に並べる。

## コンテンツと機能

価格は`src/data/pricing.json`を参照する。開設は固定5ページまで。保守と更新付きサポートを区別し、税込の目安・外部費用・作業枠など既存条件を摘要と詳細で確認できるようにする。

サービス本文は既存のlocalized contentを使う。短いカテゴリ・操作ラベルは既存の`src/i18n/ui.ts`に9言語で追加する。Web制作のヒーローの特徴はサービス詳細JSONとCMSの任意フィールド`heroBenefits`で管理する。日本語sourceを変更したら既存の翻訳状態更新を行う。有料翻訳Batchの新規投入は含めない。

検索、AIガイド、問い合わせ、SEO・構造化データ、CMS公開経路は既存のものを使う。サービス詳細からの問い合わせは`category`、`service`、`from`、`entry`を維持する。Web制作の価格CTAは同ページ内の価格摘要を指し、摘要から全条件へ進める。

## 検証

標準のformat、content、i18n、翻訳自動化、CMS、検索、AIガイド、contact、Functions型、Pages設定、build、SEOを実施する。表示と操作はin-app browserでデスクトップ・モバイル・既存翻訳ページを確認する。実画面と選択画像の比較結果はルートの`design-qa.md`に記録する。

この変更の完了範囲はDraft PRまで。マージと本番反映は別工程とする。
