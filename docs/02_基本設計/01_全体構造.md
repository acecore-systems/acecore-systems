# 全体構造

## 構成

| 区分 | 役割 |
| --- | --- |
| Astro | 9言語の公開ページと技術解説を静的出力する |
| `src/data/` / `src/content/insights/` | 構造化コンテンツと技術解説を保持する |
| Sveltia CMS | 日本語のCMS管理対象コンテンツを編集する |
| Cloudflare Pages / Functions | GitHub連携による公開とCMS保存時の検証を行う |
| Pagefind / Vectorize | 日本語のキーワード検索と関連検索を提供する |

## 公開経路

1. Pull Requestまたは対象を限定したCMS保存で`main`を更新する。
2. Cloudflare PagesのGitHub連携が公開ビルドを行う。
3. 公開済みの日本語HTMLを検索用corpusとして利用し、ProductionのVectorizeだけを同期する。
